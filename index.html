Channel Upload Assistant

Uses YouTube API Services · YouTube Terms of Service

Channel Upload Assistant is a private tool used by one creator to manage their own YouTube channels: The Wild Instinct, Provenance, आखिरी मोड़, The Last Turn, The Finance Formula, Desi Wave Beats and Dhillon Gaming.

It runs only on the creator's own computer and uses the YouTube Data API and YouTube Analytics API to:

  • upload the creator's own videos and Shorts, with titles, descriptions, tags, thumbnails and subtitles;
  • add videos to the creator's own playlists and update their metadata;
  • read the creator's own channel and video analytics to plan future videos.

It is not offered to the public and does not access anyone else's account or data.
